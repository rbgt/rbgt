### 🧭 About me

I build **reliable data platforms** and apply **probabilistic modelling** to turn raw data into decisions.

- 🟣 Strong expertise in **Microsoft Fabric**: building and operating end-to-end analytics solutions
- ⚡ Deep hands-on experience with **KQL** and **Azure Data Explorer (ADX)** for high-volume, real-time and time-series analytics
- 🗺️ Handling **geospatial data**: processing, transforming and analysing cartographic datasets
- ☁️ Designing **cloud data pipelines** on **Azure** and **GCP**: ingestion, streaming, batch ETL and data warehousing
- 🏗️ Provisioning infrastructure as code with **Terraform**, automated through **CI/CD** (GitHub Actions, Jenkins)
- 🐳 Packaging workloads in **Docker** for portable, reproducible pipelines
- 📊 Applying **Bayesian statistics** and machine learning to quantify uncertainty, not just predict a number
